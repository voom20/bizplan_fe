## 🔍 실패 원인 분석

### 1. 셀렉터 불일치
- 테스트 코드의 셀렉터가 실제 UI 요소와 정확히 일치하지 않음
- 예: `getByText(/사업계획서/i)` → 다중 요소 매칭

### 2. 인증 상태 시뮬레이션
- localStorage 설정이 페이지 로드 전에 적용되지 않음
- 보호된 라우트 접근 시 리다이렉트 발생

### 3. Mock API 미구현
- 실제 API 없이 Mock 데이터만 사용
- 로그인/회원가입 실제 동작 불가

### 4. 비동기 로딩
- Lazy Loading으로 인한 타이밍 이슈
- 요소가 렌더링되기 전에 테스트 실행
